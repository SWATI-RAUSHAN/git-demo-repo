what is git and what is github?

git :

git is a distributive version control system, which helps us to track and record the changes that we made everytime in out code.

github :

github is a service of git software which helps us to make our code interactable globally.

git commands and steps to use it

  • write "git init" command in terminal
  • write "git add . "
  • write "git commit -m "message""
  • chech status by "git status" command anytime
  • push this repository on github by "git remote add origin "
  • "git branch -M main"
  • "git push origin main"
  • now when ever make a change in code, update that in remote machine too
